# Субагенты для разработки и ручных запусков

Здесь лежат те же роли, что в `src/jobagent/agents/`, но в виде субагентов
Claude Code — чтобы запускать их руками, не дожидаясь готового пайплайна.

Готовы:

- `fact-checker` — обязательная проверка перед отправкой (Фаза 3, но нужен
  с Фазы 1, чтобы проверять первое резюме);
- `profile-builder` — заполнение мастер-профиля (Фаза 1).

Появятся по фазам: `portfolio-advisor`, `scout`, `matcher`, `resume-writer`,
`letter-writer`, `market-analyst`, `interview-coach`.

Общее для всех: факты только из `profile/master_profile.yaml`, независимые
вызовы (например, оценка пачки вакансий) запускать параллельно, Fact Checker
вызывать с чистым контекстом.
